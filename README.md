# taskai CLI

AIエージェントを組み込んだインテリジェントなタスク管理CLIアプリケーション

## 概要

taskai CLIは、自然言語処理と機械学習を活用した次世代のタスク管理ツールです。コマンドラインから簡単に操作でき、以下の機能を提供します：

- 自然言語でのタスク入力と自動分類
- 多様なフィルタリングオプション付きのタスク一覧表示
- インテリジェントな検索機能
- 優先度の低いタスクの整理支援
- 現在取り組むべきタスクの推奨

## 機能

### スマートタスク登録

```
$ task add "来週の水曜日までにプレゼン資料を準備する"
```

入力した自然言語からタスク情報を抽出し、自動的に分類します。

### タスク一覧表示

```
$ task list --category work --priority high
```

多様なフィルタリングオプションでタスクを表示できます。

### インテリジェント検索

```
$ task search "来週までの重要なタスク"
```

キーワードだけでなく、文脈も理解した検索が可能です。

### 優先度低タスクの整理

```
$ task cleanup
```

優先度の低いタスクを検出し、整理をサポートします。

### AIタスク推奨

```
$ task now
```

現在のコンテキストに基づいて、取り組むべきタスクを提案します。

## インストール

```bash
# インストール方法（準備中）
npm install -g taskai-cli
```

## 開発セットアップ

```bash
# リポジトリのクローン
git clone https://github.com/yourusername/taskai-cli.git
cd taskai-cli

# 依存関係のインストール
npm install

# 開発モードで実行
npm run dev
```
